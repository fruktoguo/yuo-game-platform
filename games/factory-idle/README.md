# 异星工厂

《异星工厂》是游戏平台内的浏览器单机放置游戏。玩法状态与存档全程保存在当前浏览器，游客无需登录即可启动；平台只接收匿名在线心跳，用于在线人数、启动次数、游玩时长和热度统计。

项目以本地参考 bundle 的模拟规则为行为基准，将原 AMD 模块恢复并重构为可读、可构建、可维护的分文件工程。交互界面、文案、地图视口与平台接入均由当前项目源码维护。

## 目录

- `src/restored/`：按 AMD 模块名拆分并整理的玩法、配置和 UI 源码。
- `src/modules/`：为移除外部依赖而重写的本地模式模块。
- `public/template/`：从 bundle 中拆出的 Handlebars 模板。
- `public/img/`：游戏运行时按原路径读取的素材。
- `scripts/reconstruct-source.mjs`：从本地参考 bundle 重建上述源码的工具。

## 操作

- 鼠标滚轮或地图右下角按钮：缩放地图。
- 未选择设施时按住左键拖动：移动地图；任意状态下可用中键拖动。
- 右键：拆除设施或传送带，浏览器原生右键菜单会在地图内被屏蔽。
- 空格键：取消当前设施，或恢复上一次选择。
- `Shift + 左键`：拆除设施；地图开发模式通过 `?dev=1` 显式开启。

主游戏共定义 44 个可放置组件，包含传送带以及横向、纵向两种分拣器。若不把传送带计作建筑，并把两种朝向的分拣器合并为同一功能类型，则为 42 类建筑。

## 命令

```bash
npm run dev -w @yuo/factory-idle
npm run build -w @yuo/factory-idle
npm run test -w @yuo/factory-idle
```

运行时固定使用浏览器本地存储，不加载广告、第三方统计、HTTP 迁移、Kongregate、PlayFab 或远端购买接口。
