# GSS0 猫猫蛇：包豪斯 / 瑞士国际主义 UI 概念套图

延续 `gss0-cat-snake-ui-concepts` 的 V133 实机截图驱动工作流，采用上一轮头脑风暴的 4 号方向「包豪斯 / 瑞士国际主义」。界面覆盖、镜头和玩法构造均与上一套保持一致，仅重做完整视觉系统。

## 不可变设计规则

1. 战斗始终是严格 2D 正俯视角，不使用等距、斜视或透视场景。
2. “猫”只承担头部识别：三角耳、表情、鼻口与朝向提示全部集中在头部。
3. 身体仍是彼此分离的独立几何机体节段；节段之间保留明显空隙，只以细线连接。
4. 玩家和七类敌人遵循同一构造规则，不出现连续动物躯干、完整蛇体或写实猫。
5. 战斗实体、机体图鉴、升级卡、底部槽位和设置图标使用同一套几何语法与颜色编码。

## 包豪斯 / 瑞士视觉规则

| 系统 | 概念映射 |
| --- | --- |
| 版式 | 非对称但严格对齐的瑞士网格、左对齐信息层级、大号数字、细黑线、编号索引与测量刻度 |
| 玩家头部 | 米白方形 / 圆形猫脸、三角耳、极简点眼与 `w` 嘴、黄色朝向楔形 |
| 身体模块 | 圆、矩形、六边形、三角形、方框与圆环；保持分节空隙与模块辨识度 |
| 攻击 | 朱红；线、圆、星爆、三角、靶心与切割符号 |
| 生存 | 群青；盾、方框、耐久条与厚重几何块 |
| 辅助 | 青绿；十字、环、准星、箭头与控制符号 |
| 发育 | 镉黄；圆片、阶梯、扩容框与资源符号 |
| 拾取物 / 弹幕 | 黄色圆片、红色激光线、蓝色圆环、鱼骨、毛线圆、叉形雷与八角爆点 |
| 战场 | 深炭黑二维网格，极少纹理，不使用霓虹辉光、渐变或透视地面 |
| UI | 象牙纸面板 + 黑色壳体；原色状态条；中性无衬线字体；方角、切角、编号页签、规则线 |

## 生成与验证

- 模型：`gpt-image-2`
- 路径：ImageGen CLI（延续上一套已确认的 Image2 工作流）
- 方法：先独立生成 `00-visual-master.png`，再以真实 V133 截图作为布局 / 信息目标、母版作为强制风格与资产参考逐屏编辑。
- 请求分辨率：`2048 × 1152`；当前服务返回的内容图为 `1672 × 941`（16:9）。
- 质量：母版 `high`；逐屏界面 `medium`。
- 总览图：本地无损缩略排版生成，`2560 × 720`。
- 最终提示词：保存在 `prompts/`；`07` 另保留一次只修正顶部玩家猫头的定向提示词。
- 视觉 QA：已检查 2D 正俯视、猫头终端位置、独立节段空隙、两名多人玩家头部、模块跨界面对应、原色编码、瑞士网格和中文主层级。

这些图片是方向性高保真概念稿，不是已切片的生产资源。正式落地时仍需重新排版细小文字，并从母版拆分猫头、模块、敌人、拾取物、弹幕、地砖、图标与 UI 九宫格资源。
