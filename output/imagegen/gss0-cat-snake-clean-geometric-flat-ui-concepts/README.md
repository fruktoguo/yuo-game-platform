# GSS0 猫猫蛇 UI / 美术概念套图 — 干净几何扁平

风格方向：**干净几何扁平 × 粗轮廓 × 猫猫表情**。

本套图延续 `gss0-cat-snake-ui-concepts` 的真实界面截图驱动流程、界面映射和 11 张交付结构。覆盖视觉母版、主菜单、两套图鉴、更新日志、联机大厅 / 等待室、单人战斗、多人战斗记分板、暂停 / 升级 / 结算，以及七类 HUD 设置浮层。

这次重做的核心不是降低彩色玻璃方案的饱和度，而是从资产构造层面删除“双重分割”、材质纹理、辉光和重复装饰，让玩家、敌人、模块、拾取物、弹幕和 UI 首先通过轮廓与大色块被识别。

## 不可变玩法与角色规则

1. 战斗始终是严格 2D 正俯视角，不使用等距、斜视或透视场景。
2. “猫”只替换头部识别层：耳形、眉眼、嘴部、表情和朝向提示集中在一个完整猫脸色块中。
3. 身体仍是彼此分离的独立机体节段；节段之间保留明显空隙，只由短而细的连接线相连。
4. 玩家和七类敌人遵循同一构造规则，不出现连续动物躯干、完整 3D 蛇或侧视猫身体。
5. 战斗实体、机体图鉴、升级卡和底部槽位使用同一套模块轮廓、图标和类别色。
6. 战斗可读性优先于主题装饰；猫元素不扩散成遍布控件的爪印、鱼骨、毛线球或耳形边框。

| 项目 | 规范 |
| --- | --- |
| 结构 | 统一近黑粗外轮廓；每个小型对象只有一个主轮廓、一个纯色填充和一个中心图标 |

| 信息面 | 暖米白纯色卡片；深蓝外壳；只在大层级使用粗边框，内部以留白和细分隔线组织信息 |
| 攻击 | 珊瑚红 `#FF6262`；尖角、三角、箭头和星形 |
| 生存 | 薄荷绿 `#67D88C`；盾形、圆角方形和厚实多边形 |
| 辅助 | 天空蓝 `#58B9F5`；圆形、圆环、十字和控制符号 |
| 发育 | 金黄色 `#F5C84B`；菱形、层叠方块和资源符号 |
| 猫头 | 暖米白完整色块、三角耳、极简眼口；用困倦、饥饿、专注、愤怒、狡黠、警觉和冷静表情区分敌人 |
| 弹幕 / 拾取 | 圆点、短线、三角、圆环、叉号、圆、菱形和六边形；一物一色一轮廓 |

- 模型：`gpt-image-2`。

- 质量：视觉母版 `high`；九组逐屏界面和定向文字修订 `medium`。
- 总览：本地无损缩略排版生成，`2560 × 720`。
- 定向修订：机体图鉴顶部旧代号和 `V133` 已改为“代号：猫猫蛇”和 `V134`；修订前版本保存在 `tmp/imagegen/gss0-cat-snake-clean-geometric-flat-ui-concepts/`。
