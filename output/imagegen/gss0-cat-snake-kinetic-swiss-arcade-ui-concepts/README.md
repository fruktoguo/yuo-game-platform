# GSS0 猫猫蛇：动势包豪斯 / Kinetic Swiss Arcade UI 概念套图

延续 `gss0-cat-snake-ui-concepts` 的 V133 实机截图驱动工作流，并对上一套纯「包豪斯 / 瑞士国际主义」方案进行战斗化改造。本套保留瑞士网格、几何模块和大号数字，但把竞技场、功能色、运动重影和命中反馈重新设计为适合快节奏街机玩法的高能系统。

## 不可变规则

1. 战斗始终是严格 2D 正俯视，不使用等距、斜视或透视场景。
2. 猫只承担头部识别；猫头必须位于运动方向最前端。
3. 身体仍由彼此分离的独立几何模块构成；节段间保留明显空隙，只以细线连接。
4. 玩家和七类敌人使用同一构造语法，不出现连续动物躯干、完整蛇体或写实猫。
5. 战斗实体、机体图鉴、升级卡和底部槽位使用对应形状与功能色。

## 动势视觉系统

| 系统 | 概念映射 |
| --- | --- |
| 基础结构 | 瑞士基线网格、左对齐排版、超尺度数字、编号索引、硬边切角与非对称布局 |
| 运动语言 | 斜向色带、方向楔形、短促速度线、两帧套色重影、局部径向爆发与色版错位 |
| 玩家 | 米白猫头；电青 + 酸黄轮廓；拾取物和玩家弹幕保持白 / 青 / 黄高亮 |
| 敌人 | 洋红、朱红、橙、紫等暖色或敌对色组；不同耳形、眉眼与模块节奏 |
| 攻击模块 | 洋红 / 朱红；三角、靶心、星爆、切割线和爆裂圆环 |
| 生存模块 | 钴蓝 / 酸绿；盾、加号、厚重方框和耐久条 |
| 辅助模块 | 电青 / 青绿；环、箭头、磁吸、准星和冷却符号 |
| 发育模块 | 酸黄 / 信号橙；资源圆片、阶梯、扩容框和经验符号 |
| 战场 | 深炭黑二维网格，减少浅色面板占比，使竞技场成为视觉主体 |
| 战斗效果 | 白色核心闪光、三级硬边爆点、伤害大数字、短辉光和套色余像；避免粒子雾遮挡 |
| UI | 紧凑深色 HUD、高亮功能色条、米白只用于文字、短暂闪白及菜单 / 结算关键面板 |

## 生成与验证

- 模型：`gpt-image-2`
- 路径：ImageGen CLI（延续当前任务已确认的 Image2 工作流）
- 母版方法：以纯包豪斯母版作为几何 / 网格参考，以最初猫猫蛇母版作为颜色 / 战斗资源参考，重新生成混合视觉系统。
- 逐屏方法：真实 V133 截图作为布局与信息目标，`00-visual-master.png` 作为强制风格、模块和效果参考。
- 请求分辨率：`2048 × 1152`；当前服务返回内容图为 `1672 × 941`（16:9）。
- 质量：母版 `high`；逐屏界面 `medium`。
- 总览图：本地无损缩略排版生成，`2560 × 720`。
- 最终提示词：保存在 `prompts/`；另保留单人和多人战斗的运动方向定向修正提示词。
- 视觉 QA：已检查 2D 正俯视、猫头终端位置、节段空隙、速度重影方向、两名多人玩家区分、模块跨界面对应、战斗色彩层级及粒子遮挡。

这些图片是方向性高保真概念稿，不是已切片的生产资源。正式落地时需重新排版细小文字，并从母版拆分猫头、模块、敌人、拾取物、弹幕、命中特效、地砖、图标和 UI 九宫格资源。
